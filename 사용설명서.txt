설교 쇼츠 메이커 — 사용 설명서
================================

1. 앱 사용법 (4단계)
--------------------
1) 설교 유튜브 링크를 넣고 Gemini API 키를 입력한 뒤 "하이라이트 찾아 쇼츠 만들기"를 누릅니다.
2) AI가 찾은 쇼츠 목록에서 만들 쇼츠를 고릅니다.
3) 24종 디자인 중 하나를 고릅니다.
4) "이 디자인으로 쇼츠 만들기"를 누르면 영상이 만들어집니다. 만든 영상은 MP4로 받아 유튜브 스튜디오에서 직접 올립니다.

2. Gemini API 키 받는 법 (무료)
--------------------------------
1) https://aistudio.google.com/apikey 에 들어갑니다 (구글 로그인 필요).
2) "Create API key"를 눌러 키를 만듭니다.
3) 키를 복사해서 앱의 "Gemini API 키" 칸에 붙여넣습니다.
4) 키는 목사님 PC에만 저장되고, 다른 곳으로 보내지지 않습니다.

3. 유튜브에 직접 올리는 법 (7단계)
----------------------------------
1) 4단계 화면에서 MP4 파일을 받습니다.
2) 유튜브 스튜디오(studio.youtube.com)를 엽니다.
3) 오른쪽 위 "만들기" → "동영상 업로드"를 누릅니다.
4) 받은 MP4 파일을 선택합니다.
5) 앱의 "직접 올리기" 버튼에서 제목·설명·해시태그를 복사해 붙여넣습니다.
6) 공개 상태를 "예약"으로 바꾸고 날짜·시간을 정합니다.
7) "게시"를 누르면 예약된 시간에 자동으로 공개됩니다.

4. 자주 묻는 문제
------------------
- 링크만 넣으면 되나요? — 네. 교안 입력은 없습니다. 링크만으로 분석합니다.
- 자막이 없는 영상이면요? — 원고 문장으로 자막을 대신 만듭니다.
- 영상이 안 받아질 때 — 링크가 공개 영상인지 확인해 주세요. 비공개·연령 제한 영상은 안 됩니다.
- 앱이 안 켜질 때 — 압축을 다시 풀고, 풀린 폴더 안의 exe를 더블클릭해 주세요.
- 오류가 뜨면 — 앱을 완전히 껐다가 다시 켜고, 같은 문제가 반복되면 아래 문의처로 알려주세요.
